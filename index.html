Nuestro desarrollo

AT-2026 PRO

El AT-2026 PRO es nuestro desarrollo de brazo robótico con soldadora de punto. Está diseñado como una propuesta de automatización para realizar movimientos controlados y operaciones de unión de piezas metálicas.

  • Cuatro grados de libertad.
  • Control electrónico mediante Arduino.
  • Movimiento gestionado mediante joysticks.
  • Estructura mecánica articulada.
  • Sistema de soldadura de punto.
  • Integración de electrónica y mecánica.
  • Proyecto desarrollado en equipo.

Funcionamiento

¿Cómo funciona nuestro brazo robótico?

El sistema utiliza controles manuales y componentes electrónicos para gestionar los movimientos del brazo y ejecutar las operaciones previstas. El operador envía las instrucciones y el controlador procesa las señales para coordinar los movimientos.

01

Control del operador

El usuario utiliza los joysticks para indicar los movimientos que debe realizar el mecanismo. Cada movimiento genera señales que son enviadas al sistema electrónico.

02

Procesamiento

Arduino recibe las señales de entrada y procesa las instrucciones programadas. El código establece cómo deben responder los distintos componentes.

03

Movimiento

Los motores y mecanismos realizan los movimientos correspondientes de las articulaciones, permitiendo desplazar el brazo de manera controlada.

04

Posicionamiento

El brazo se coloca en la posición necesaria para realizar la operación prevista, de acuerdo con las instrucciones enviadas por el operador.

05

Soldadura

El sistema de soldadura de punto permite realizar la unión de piezas metálicas mediante corriente eléctrica, presión y calor generado por resistencia.

06

Verificación

Se comprueba el resultado y el funcionamiento del conjunto mecánico y electrónico para identificar posibles ajustes o mejoras.

Ingeniería aplicada

Tecnología y componentes.

El proyecto integra diferentes áreas de la ingeniería: electrónica, programación, mecánica y fabricación. Cada componente cumple una función importante para conseguir el funcionamiento del conjunto.

💻

Arduino

Es el cerebro electrónico del proyecto. Recibe las señales de los controles, procesa las instrucciones programadas y coordina las acciones de los motores y demás componentes. Permite adaptar el comportamiento del brazo mediante código.

🕹️

Joysticks de control

Permiten al operador manejar los movimientos del brazo de manera manual. Sus señales analógicas son interpretadas por Arduino para controlar los desplazamientos y facilitar el posicionamiento del mecanismo.

⚙️

Motores paso a paso

Son los encargados de producir movimientos controlados en las articulaciones. Reciben señales del sistema de control y permiten realizar desplazamientos de forma organizada y coordinada.

🔩

Estructura mecánica

Está formada por la base, los brazos y las articulaciones. Su función es sostener los componentes, distribuir las cargas y permitir que el mecanismo alcance diferentes posiciones de trabajo.

⚡

Soldadora de punto

Es el sistema destinado a unir piezas metálicas mediante calor generado por resistencia eléctrica y presión. Su funcionamiento requiere una alimentación adecuada y medidas de protección específicas.

🧠

Programación y electrónica

El código desarrollado en Arduino IDE establece cómo interpretar los controles y generar las señales necesarias para el movimiento. El cableado conecta los módulos, sensores y actuadores del proyecto.
