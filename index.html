Nuestro desarrollo

AT-2026 PRO

El AT-2026 PRO es nuestro desarrollo de brazo robótico con soldadora de punto. Está diseñado como una propuesta de automatización para realizar movimientos controlados y operaciones de unión de piezas metálicas.

  • Cuatro grados de libertad.
  • Control electrónico mediante Arduino.
  • Movimiento gestionado mediante joysticks.
  • Estructura mecánica articulada.
  • Sistema de soldadura de punto.
  • Integración de electrónica y mecánica.
  • Proyecto desarrollado en equipo.

Funcionamiento

¿Cómo funciona nuestro brazo robótico?

El sistema utiliza controles manuales y componentes electrónicos para gestionar los movimientos del brazo y ejecutar las operaciones previstas. El operador envía instrucciones y el controlador procesa las señales para coordinar los movimientos.

01

Control del operador

El usuario utiliza los joysticks para indicar los movimientos. Cada movimiento genera señales que se envían al sistema electrónico.

02

Procesamiento

Arduino recibe las señales de entrada y procesa las instrucciones programadas para establecer cómo responden los componentes.

03

Movimiento

Los motores y mecanismos realizan los movimientos correspondientes de las articulaciones de forma controlada.

04

Posicionamiento

El brazo se coloca en la posición necesaria para realizar la operación prevista, de acuerdo con las instrucciones del operador.

05

Soldadura

La soldadura de punto une piezas metálicas mediante corriente eléctrica, presión y calor generado por resistencia.

06

Verificación

Se comprueba el resultado y el funcionamiento del conjunto mecánico y electrónico para identificar ajustes o mejoras.

Ingeniería aplicada

Tecnología y componentes.

El proyecto integra electrónica, programación, mecánica y fabricación. Cada componente cumple una función para conseguir el funcionamiento del conjunto.

💻

Arduino

Recibe las señales de los controles, procesa las instrucciones programadas y coordina las acciones de los motores y otros componentes.

🕹️

Joysticks de control

Permiten manejar manualmente los movimientos. Sus señales son interpretadas por Arduino para controlar desplazamientos y posicionamiento.

⚙️

Motores paso a paso

Producen movimientos controlados en las articulaciones, siguiendo las señales del sistema de control.

🔩

Estructura mecánica

Base, brazos y articulaciones sostienen los componentes, distribuyen las cargas y permiten diferentes posiciones de trabajo.

⚡

Soldadora de punto

Sistema destinado a unir piezas metálicas mediante calor por resistencia eléctrica y presión. Requiere alimentación adecuada y protecciones específicas.

🧠

Programación y electrónica

El código en Arduino IDE interpreta los controles y genera señales para el movimiento. El cableado conecta módulos, sensores y actuadores.

🔨 Etapas del proceso de soldadura

1. Posicionamiento

Se colocan las piezas metálicas en la posición adecuada.

2. Presión

Los electrodos mantienen las piezas en contacto.

3. Corriente

Se aplica energía eléctrica controlada.

4. Calentamiento

La resistencia eléctrica genera calor en la zona de unión.

5. Unión

Se forma el punto de soldadura entre las piezas.

6. Enfriamiento

El material se solidifica y consolida la unión.

Nuestro proceso

De una idea a un proyecto real.

El desarrollo requiere organización, planificación, fabricación y pruebas. Cada etapa aporta conocimientos y permite mejorar el resultado final.

06. Pruebas y mejoras
